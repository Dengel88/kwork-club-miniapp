# Контекст для Claude

Заказ с Kwork #3268232 — личный кабинет клиента салона в виде Telegram Mini App и мини-приложения MAX.
Работаем по схеме «сначала MVP, потом предлагаем заказчику готовое решение».

- Фронтенд: `web/` (Vite + React + TypeScript, без UI-библиотек, стили в `web/src/index.css`).
- Платформенные различия Telegram/MAX — только в `web/src/platform.ts`. Компоненты не трогают `window.Telegram`/`window.WebApp` напрямую.
- Данные — только через `web/src/api/client.ts`. Реальный контракт API ещё не выдан; модель в `types.ts` — предположение по ТЗ.
- Язык интерфейса и комментариев — русский.
- Перед коммитом: `cd web && npm run build` должен проходить без ошибок.
- Ручной ввод номера телефона допустим только в демо/браузере (см. README, раздел про безопасность).
